# 지식 노트 작성법

이 폴더(`knowledge/notes/`)에 `.md` 또는 `.txt` 파일을 자유롭게 추가하면
AI 플래너가 매 판단마다 참고한다. 서버 재시작 불필요 — 저장 즉시 반영된다.

규칙:
- **`always.md`** 에 쓴 내용은 **모든 판단에 항상** 주입된다. 행동 지침용.
  (또는 아무 파일에서나 제목에 '항상'이 들어간 섹션도 동일하게 취급)
- 그 외 파일은 `#`/`##` 제목 단위로 잘라서, **현재 상황(존, 방, 몹, 목표,
  상태이상 등)과 키워드가 겹치는 섹션만** 상위 3개까지 골라 주입된다.
- 따라서 제목에 존 이름, 몹 이름, 명령어 같은 키워드를 넣을수록 잘 검색된다.
  예: `## 훈련장 사냥 요령`, `## 발해 가는 길`, `## 배고픔 해결`
- 파일 개수 제한 없음. 한 섹션은 몇 문장 정도로 짧게 쓰는 것이 좋다
  (로컬 8B 모델이라 프롬프트가 길면 판단력이 떨어진다).

이 README 자체는 키워드가 겹치지 않는 한 주입되지 않는다.
