## Waking from sleep — the poll/watchdog (user: how does it know when to wake?)
Problem: while asleep the server pushes no prompt, so vitals freeze and recovery is invisible; a long sleep also risks the idle-kick.
- Engine WATCHDOG: if no real prompt for [rest].watchdog (12s), send [rest].poke ("점수") to pull a fresh prompt. 점수 now updates CURRENT hp/mp (state.apply Status), so recovered can be judged on real numbers; also serves as keep-alive. ctx.last_prompt_at (set on Prompt) drives the quiet detection; tick() runs the arbiter on at_prompt AND pokes when quiet.
- rest wakes on `recovered` (fresh vitals via poll) OR `stuck:300` cap; wait wakes on `regen_done` (elapsed time) — the heartbeat + watchdog keep it alive through the ~20m regen.
- Test: test_hunt_cycle.test_rest_poll_and_wake (quiet -> 점수 poll; stays asleep while low; wakes when the poll shows recovered). All 6 suites green. Server restarted.
- NOTE: poke defaults to 점수 (verbose but reliably yields current vitals); switch [rest].poke to "" or a lighter command if 점수 works differently while asleep on this server.
